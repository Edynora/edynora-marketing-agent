Coverage: native async TypeScript coordinates agents/workflows and approval state; Zod handles structured content and brand validation; remark handles document ingestion and content extraction; original templates provide social and email formatting; native exporters provide CSV/JSON/Markdown. Vitest covers testing; structured errors and local audit history cover observability without remote telemetry.

Maintenance assessment: npm resolves current published versions for the selected packages, and upstream repositories provide source and issue/security channels. This is a point-in-time assessment, not a comprehensive project health rating. Run `npm audit` on the locked graph; see FINAL_REPORT.md for the actual executed results. Reference-only projects were not installed and have not received a full transitive vulnerability audit.

MIT permits commercial use with copyright and permission notices preserved. Apache-2.0 permits commercial use with license, notice and modification obligations, plus its patent terms. Activepieces enterprise components impose commercial terms and are excluded. No unverified commercial-use permission is asserted for its shared package. Recheck licenses when upgrading. Installed package license texts are copied by `npm run licenses`, including development/transitive dependencies and optional platform packages actually present.
