# Architecture decisions

1. **Local-first modular monolith.** `packages/core` coordinates `brand`, `content`, `strategy`, `campaigns`, `quality`, `exporters`, `shared` and `adapters`. One npm distribution avoids workspace installation ambiguity on Windows. Files retain the requested package boundaries.
2. **Generation.** Offline extractive templates are the shipped implementation, explicitly labeled `template-v1`. Model-provider interfaces accept untrusted content as data and require validated output. No external AI provider, paid API call, or provider support is implied. Compared with a LangChain dependency this limits attack surface; compared with a plugin-only product it preserves independent CLI use.
3. **Storage.** Versioned JSON state in a user-selected workspace; reject traversal, symlinks and oversized inputs. Exclusive lock and atomic replacement prevent concurrent lost updates. This is a single-user store, not a tamper-proof or multi-tenant database.
4. **Approval.** Immutable revision snapshots and events; review precedes explicit named approval. Editing invalidates approval. Export requires every item approved at its current revision. Imported approval metadata never grants local approval. Re-export is allowed and logged.
5. **Sources.** Preserve originals and extracted text; no URL downloading or code execution. Generated text cites local source IDs; attribution is traceability, not verification. Heuristic quality checks highlight risk and cannot certify factual accuracy or legal compliance.
6. **Adapters.** Claude Code skills and commands delegate to a fixed Node bridge and the CLI. No interpolated shell execution of imported data. Future provider and publisher interfaces have no implementations and cannot publish. Actual Claude model invocation remains untested unless explicitly recorded, because paid API use is not authorized.
7. **Contract.** A proposed Edynora Video Workflow contract v1.0.0 is provided. No existing Video Workflow schema was supplied; compatibility is structural within this repository, not verified interoperability with another product. Unknown versions fail; migrations require an explicit future converter.
8. **Licensing.** Apache-2.0 covers original work. The project owner confirmed `copyright 2026 edynora`; original code and NOTICE use `Copyright 2026 Edynora`. This is the owner's attribution, not an independent legal ownership investigation.
