# 0.1.0-alpha.1 — acceptance candidate

Includes independent CLI, strict brand profiles, local source ingestion, nine offline draft formats, planning strategy, 7/30-day calendars, five email types, quality reports, revision history, explicit review/approval, protected local exports, proposed shared video contract, Claude skill/command adapter, automated tests and cross-platform CI configuration.

Generation is deterministic template-v1. No AI provider, publisher, scheduler, email sender or external automation integration is implemented. Calendar slots and email sequences are starting points needing human editing. Template excerpts can lose context through truncation. Heuristic checks cannot certify facts or legal compliance.
