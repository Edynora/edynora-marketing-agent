- Windows/Linux/macOS × Node 22/24/26 CI: see the [latest checks run](https://github.com/Edynora/edynora-marketing-agent/actions/workflows/ci.yml) for the authoritative result. Workflow also checks schemas, licenses, dependency audit, package creation and a clean offline package installation.
- Claude command loading/tool execution: passed against a loopback-only deterministic mock; zero paid calls. This is not evidence of live model behavior.

API credentials were removed from that child process and API-key fallback was refused. Included subscription allowance was consumed; no paid API-key calls were made. Evidence: [claude-subscription-evidence.json](claude-subscription-evidence.json).
